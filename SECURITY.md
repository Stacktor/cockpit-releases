# Sicherheitslücken melden

Bitte meldet Sicherheitsprobleme nicht als öffentliches Issue, sondern per Mail an
**Kontakt@mesco.cc** mit dem Betreff „Sicherheit“. Hilfreich sind die App-Version
(Einstellungen → System), das Betriebssystem und eine kurze Beschreibung, wie sich das Problem
nachstellen lässt.

Ich melde mich so bald wie möglich und sage Bescheid, wann ein Update kommt. Wer möchte, wird im
Changelog genannt.

## Was hierher gehört

- die Installer und das Update-Verfahren (`latest.json`, Signaturen)
- die App selbst, die Browser-Erweiterung und der Geräte-Sync
- die Website und die Schnittstellen unter `cockpit.mesco.cc/api/`

## Unterstützte Versionen

Während der Alpha bekommt nur die jeweils neueste Version Sicherheitsupdates.
